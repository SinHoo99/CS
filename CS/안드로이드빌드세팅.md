# Unity Android 빌드 설정 정리 (Unity 2021.3 LTS 기준)

> **출처**: Unity 2021.3 LTS 매뉴얼 — [Android 빌드 설정](https://docs.unity3d.com/kr/2021.3/Manual/android-build-settings.html)  
> 이 문서는 Build Settings의 Android 항목을 표 형식으로 정리하고, 각 항목별 부가 설명을 추가한 실무용 가이드입니다.

---

## 1. 기본 빌드 절차

| 단계 | 설명 | 부가 설명 |
|------|------|-----------|
| 1 | **File ▶ Build Settings** 열기 | Android 빌드 관련 모든 설정은 여기서 시작 |
| 2 | **Platform ▸ Android** 선택 | Android SDK/NDK/JDK가 설치되어 있어야 활성화 |
| 3 | Android 항목이 회색이면 **SDK/NDK/JDK 설치** 필요 | Unity Hub에서 Android Build Support 추가 설치 가능 |
| 4 | **Switch Platform** 클릭 | 현재 플랫폼을 Android로 전환(모든 에셋 재임포트) |
| 5 | Android 전용 옵션 설정 후 **Build / Build And Run** | 옵션에 따라 APK, AAB, Gradle 프로젝트로 빌드 가능 |

---

## 2. Android Build Settings 항목별 설명

| 항목 | 설명 | 주요 선택지 / 값 | 부가 설명 |
|------|------|-----------------|-----------|
| **Texture Compression** | 텍스처 압축 포맷 | Use Player Settings / ETC / ETC2 / ASTC / DXT / PVRTC | 기기 GPU 지원 여부에 따라 선택. ETC2 이상 권장, ASTC는 고품질 |
| **ETC2 fallback** | ETC2 미지원 기기 폴백 포맷 | 32-bit / 16-bit / 32-bit half resolution | 구형 기기 대응용. 메모리 절약이 필요하면 16-bit |
| **Export Project** | Gradle 프로젝트로 내보내기 | On / Off | Android Studio에서 빌드/수정 가능. 플러그인 통합 시 유용 |
| **Symlink Sources** | Export 시 Unity 소스를 심볼릭 링크 | On / Off *(Export Project 활성 시)* | 반복 빌드 속도 향상. Windows 일부 환경에서 권한 이슈 가능 |
| **Build App Bundle** | APK 대신 AAB 빌드 | On / Off *(Export Project 비활성 시)* | Google Play 배포 표준. 기기별 다운로드 최적화 |
| **Export for App Bundle** | Export 시 AAB 빌드 구조로 내보내기 | On / Off *(Export Project 활성 시)* | Android Studio에서 AAB 빌드 예정 시 활성 |
| **Create symbols.zip** | 심볼 파일 생성 | Disabled / Public / Debugging | 크래시 리포트 분석 시 필수. Debugging은 내부용 |
| **Run Device** | Build & Run 대상 기기 | 연결된 기기 목록 | USB 디버깅 활성화 필요. ADB 드라이버 설치 필수 |
| **Build to Device** | 변경 파일만 패치 빌드 | Patch / Patch And Run *(Development Build 필요)* | 빌드 속도 대폭 향상, 단 최초 빌드 후 사용 가능 |
| **Development Build** | 개발용 빌드 플래그 | On / Off | 조건부 컴파일(`DEVELOPMENT_BUILD`) 및 디버그 심볼 포함 |
| **Autoconnect Profiler** | 실행 시 프로파일러 자동 연결 | On / Off | 성능 분석 자동화에 유용 |
| **Deep Profiling Support** | 모든 함수 호출 계측 | On / Off | 성능에 큰 부담, 병목 분석 시만 사용 |
| **Script Debugging** | C# 스크립트 디버그 허용 | On / Off | Visual Studio, Rider 등에서 브레이크포인트 사용 가능 |
| **Wait For Managed Debugger** | 디버거 연결 전 실행 대기 | On / Off *(Script Debugging 필요)* | 원격 디버깅 시 초기화 코드 분석에 유용 |
| **Compression Method** | 빌드 데이터 압축 방식 | Default(ZIP) / LZ4 / LZ4HC | LZ4는 개발 빌드, LZ4HC는 릴리스 빌드에 권장 |

---

## 3. Compression Method 비교

| 방식 | 특징 | 추천 사용처 | 부가 설명 |
|------|------|------------|-----------|
| **Default (ZIP)** | 압축률 높음 / 로딩 속도 느림 | 릴리스 빌드 기본값 | Google Play에 올릴 APK/AAB 용량 최소화 |
| **LZ4** | 압축/해제 속도 빠름 / 압축률 낮음 | 개발 빌드, 빠른 반복 | 테스트 시 로딩 속도 개선 |
| **LZ4HC** | 압축률 높음 / 빌드 시간 증가 | 릴리스 빌드, 로딩 개선 | LZ4 대비 빌드 시간이 더 오래 걸림 |

---

## 4. ETC2 Fallback 비교

| 옵션 | 장점 | 단점 | 부가 설명 |
|------|------|------|-----------|
| **32-bit** | 최고 품질 | 메모리 사용량 높음 | 고사양 기기 전용 |
| **16-bit** | 메모리 절약 | 색 정밀도 손실 가능 | 메모리 제한 기기 대응 |
| **32-bit half res** | 메모리 절감 | 해상도 절반으로 품질 저하 | 품질 희생 감수 시 적합 |

---

## 5. 추천 워크플로우

| 상황 | 추천 설정 | 부가 설명 |
|------|-----------|-----------|
| 내부 테스트 | Development Build + Autoconnect Profiler | 병목 지점 빠르게 파악 가능 |
| 반복 테스트 속도 | Build to Device (Patch/Run) | 씬/리소스 잦은 변경 시 |
| Google Play 배포 | Build App Bundle(AAB) | 기기별 다운로드 최적화 |
| 크래시 분석 | Create symbols.zip (Public/Debugging) | 스택트레이스 해석 가능 |
| 구형기기 대응 | ETC2 + 적절한 Fallback | 호환성 보장 |
| 네이티브 코드 수정 | Export Project + Symlink Sources | Android Studio로 빠른 통합 |

---

## 6. 문제 해결 체크리스트

| 문제 | 확인할 것 | 부가 설명 |
|------|-----------|-----------|
| Android 비활성 | SDK/NDK/JDK 설치 및 경로 설정 | Preferences ▶ External Tools |
| Build 버튼 회색 | Switch Platform 수행 여부 | 변경 시 에셋 재임포트 |
| AAB 옵션 없음 | Export Project 비활성 상태여야 함 | Gradle Export 시 UI 다름 |
| Patch/Profiler 옵션 회색 | Development Build 필요 | 디버그용 빌드에서만 사용 가능 |
| 용량/로딩 문제 | Compression Method / Texture Compression 재검토 | ASTC/ETC2 활용 |

---

## 7. 관련 경로
- **Build Settings**: `File ▶ Build Settings ▶ Android`
- **Player Settings**: `Edit ▶ Project Settings ▶ Player ▶ Android`
- **Profiler**: `Window ▶ Analysis ▶ Profiler`
